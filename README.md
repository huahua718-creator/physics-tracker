# Physics Tracker（物理運動慢動作影像追蹤與師生協作系統）

免安裝 App、跨平台（iOS Safari / Android Chrome / Windows / macOS）的物理運動實驗分析系統。結合**手機端離線逐幀影像質心追蹤**與**大屏／筆電端即時投影、曲線擬合與 Excel 匯出**，適合高中與國中物理課堂示範及分組探究實驗。

---

## 🌟 核心功能特色

1. **離線非即時逐幀解析 (Non-realtime Step Frame Extraction)**：
   - 以步進器逐幀讀取影片座標，不受即時串流掉幀影響，支援 `30 / 60 / 120 / 240 FPS` 高幀率慢動作影片（自動濾除低原生幀率重複幀）。
2. **單點追蹤 ＆ 雙點比較模式 (Dual-Point Comparison)**：
   - 支援追蹤單一運動物體，或切換為 **🔴🔵 雙點比較模式 (A + B)**（例如兩顆不同色球同時自由落體、斜拋對比、兩台滑車碰撞前後），共用同一物理座標原點與比例尺進行對比。
3. **手機長按拖曳上方放大準心**：
   - 手機螢幕小時，長按拖曳影片會在**手指正上方 50 px** 顯示取樣點與 **2.6 倍圓形放大鏡**，避免手指遮擋球體或尺標端點。
4. **物理數值平滑與水平校正引擎**：
   - 支援兩點標定實際距離（公尺）與任意水平傾角旋轉校正。
   - 採用 **9 點二次多項式 Savitzky-Golay 濾波**與二階中心差分計算位移 $(x, y)$、速度 $(v_x, v_y, |v|)$ 與加速度 $(a_x, a_y, |a|)$。
5. **大屏／筆電端數據分析與互動同步**：
   - **左 1/3 數據表 ＋ 右 2/3 圖表**：可縮放 Y 軸 / 時間軸、一鍵聚焦起伏區間。
   - **雙向同步選點**：點擊表格列、圖表曲線上任意點或影片上的殘影點，三者與播放時間同步高亮鎖定。
   - **曲線擬合 (Curve Fitting)**：支援二次拋物線（自動反推等加速度 $a = 2A$）、一次線性與常數回歸，即時計算 $R^2$ 與 RMSE。
   - **多元匯出與專案封存**：
     - 📥 **匯出 Excel (`.xlsx`)**（含點 A、點 B 與兩點差值工作表，離線自動降級 CSV）。
     - 🎬 **匯出標記分析影片 (`.webm`)**（含殘影軌跡、十字準心、白板筆跡與左上角即時物理數據）。
     - 💾 **儲存 / 載入專案 (`.ptproj.json`)**（15 MB 以下影片自動內嵌於專案檔中方便傳閱）。
6. **免設定 WebRTC P2P 直連傳輸**：
   - 透過 QR Code / 6 碼房間 PIN 即可用 PeerJS 建立點對點通道，無需架設後端資料庫；另有 Firebase Realtime Database 可選配作為校網防火牆備援。

## 🧪 擴充實驗室 Hub（單一 QR Code 切換 6 大模組）

在 [index.html](index.html) 待機頁或左上角 **「🧪 實驗切換」** 抽屜可直接切換模式，所有已連線手機會同步切換至「**2. 感測實驗**」分頁（支援最多 6 台手機同時連入，以紅/藍/綠/黃等節點色區分）：

1. **⚡ 三軸加速度與視重 (`ACCEL_3D`)**：3D 空間姿態向量、電梯模擬體重計（超重/失重換算）、10 秒多機 $a-t$ 折線圖、梯形積分計算 $\Delta v = \int a\,dt$。
2. **📐 斜面力學與量角器 (`INCLINE_GYRO`)**：即時繪製傾斜角 $\theta$ 與 $mg / mg\sin\theta / N$ 分力向量；滑動瞬間自動鎖定最大靜摩擦係數 $\mu_s = \tan\theta_s$；角速度過零偵測自動計算單擺週期 $T$ 與重力加速度 $g$。
3. **🎵 聲波示波與頻譜儀 (`AUDIO_FFT`)**：拋物線內插 0.1 Hz 精度主頻與音名辨識、128 頻段即時頻譜 / 瀑布圖切換、350～550 Hz 雙機拍頻放大視窗。
4. **⏱️ 聲學碼錶測 $g$ 值 (`ACOUSTIC_TIMER`)**：手機本地以 AudioContext 硬體採樣率偵測拍手/撞擊雙聲觸發（含 150 ms 防回音盲區），自動計算 $\Delta t$ 與 $g = 2h/\Delta t^2$。
5. **🚧 鏡頭光電閘計時器 (`CAM_PHOTOGATE`)**：後鏡頭中央 $20\times20$ 亮度遮光偵測，支援環境光一鍵自動校準、直線測速 $v = d/\Delta t$、雙光電閘加速度與轉盤 RPM 測量。

> 📱 **iOS Safari 提醒**：受限於蘋果安全機制，大屏廣播切換模式後，請在手機端親自點擊畫面上的 **「⚡ 啟動感測器並開始實驗」** 按鈕完成動作/麥克風/鏡頭授權；請務必透過 Vercel HTTPS 網址開啟。

## 📖 課堂使用教學

### 步驟一：開啟大屏／筆電接收端
1. 使用教師大屏或學生分組筆電瀏覽器開啟網頁首頁（例如已部署的 Vercel 網址 `https://你的網址.vercel.app/`）。
2. 畫面中央會自動產生專屬 **6 碼 ROOM PIN** 與 **QR Code**（每組電腦都會獲得獨立 PIN，同班多組同時做實驗不會互相干擾）。

### 步驟二：手機掃碼配對並設定追蹤
1. 用手機相機掃描大屏 QR Code（或開啟 `/mobile.html` 輸入 6 碼 PIN）。
2. 點擊 **「📁 選取手機影片」** 載入實拍實驗影片（或點 **「🧪 示範拋體影片」** 立即體驗）。
3. **選擇追蹤模式**：
   - **🔵 單點追蹤**：分析單一物體運動。
   - **🔴🔵 雙點比較 (A+B)**：點擊「選取點 A 色」與「選取點 B 色」分別對準兩個不同顏色的物體（例如紅球與藍球）。
4. **長按拖曳取色 ＆ 尺標校準**：
   - 在影片畫面上**長按並拖曳手指**，手指上方 50px 會出現十字準心與 **2.6 倍放大鏡**，對準球體核心後放開即可取色。
   - 切換至 **「📏 兩點標定尺標」**，依序長按拖曳設定參考尺的起點 **P1** 與終點 **P2**，並輸入實際公尺長度（例如 `1.0 m`）；系統會自動校正傾斜角度。
5. **設定分析區間與 FPS**：
   - 拖曳預覽時間軸到物體剛離開手的位置點 **「設為目前（開頭）」**，拖曳到實驗結束處點 **「設為目前（結尾）」**。
   - 依實際拍攝幀率選擇 **30 / 60 / 120 / 240 FPS**。

### 步驟三：分析、投影與數據處理
1. 點擊 **「🚀 開始逐幀分析軌跡」**，手機端將離線算出物理座標與速度／加速度，完成後自動將數據與原影片傳送到大屏／筆電。
2. 在大屏端可進行以下操作：
   - **互動教學**：開啟右下角即時圖表，切換 `x-t / y-t`、`v-t`、`a-t` 與縮放聚焦；點擊右上 **「✏️ 白板」** 切換手寫畫筆或 **🎯 選取影像點**。
   - **深入分析**：點擊頂部 **「📑 數據分析」**，切換為「左 1/3 數據表 ＋ 右 2/3 大圖表」，執行 **「✨ 執行擬合」**（拋體 $y-t$ 可直接反推重力加速度 $g = 2A$ 與判定係數 $R^2$）。
   - **帶走成果**：
     - 點擊 **「📥 匯出 Excel」** 下載 `.xlsx` 整理實驗報告。
     - 點擊 **「💾 專案/影片」** 可 **匯出含殘影軌跡的 `.webm` 分析影片**，或 **儲存 `.ptproj.json` 專案檔** 供下次課堂直接「📂 載入專案」還原現場！

## 👩‍🏫 分享給其他老師與課堂執行建議

1. **直接分享網址即可使用（Zero-Setup）**：
   - 建議將此專案部署於 Vercel（或 GitHub Pages），把網址做成短網址或 QR Code 貼在投影片上，其他老師或學生打開就能各自使用，**不會搶到同一個房間，也不會消耗您的帳號額度**。
   - 若老師們想自行修改程式碼或客製化預設文字，只需到您的 GitHub Repository 點選 **Fork**，再連上自己的 Vercel 帳號即可擁有獨立版本。
2. **網路連線與 240fps 拍攝小技巧**：
   - **同一個 Wi-Fi 最穩**：若學校無線網路（如 TANet 學術網路）封鎖裝置間 P2P 直連，建議讓筆電與手機連到**同一台分享器**或開啟**手機熱點給分組筆電連**。
   - **影片長度建議 2～5 秒**：240fps 原檔體積較大（常達數十 MB），建議課堂實拍後先在手機相簿剪掉頭尾多餘秒數，傳輸與分析速度會快非常多；傳輸期間請保持手機螢幕亮起。
3. **分組協作流程推薦**：
   - 每組（2～4 人）拿一台筆電/平板開首頁當「小組工作台」，1 位同學用手機掃該筆電的 QR Code 拍實驗與分析，傳到筆電後全組圍著筆電討論擬合結果、匯出 Excel 與分析影片寫實驗學習單。

## 🔥 預設 Firebase 設定與更換成自己的 Firebase Config

本專案已在 [js/firebase-config.js](js/firebase-config.js) 內建預設的 Firebase Realtime Database 作為跨網域／校網防火牆時的雲端備援通道，開箱即可運作。

若其他老師或團隊希望改用**自己的 Firebase 資料庫**（避免共用流量或配合自架站台），有兩種設定方式：

### 方法一：直接於網頁「⚙️ 設定」覆寫（免改程式碼）
1. 至 [Firebase Console](https://console.firebase.google.com/) 建立專案並啟用 **Realtime Database**（區域建議選 `asia-southeast1` 新加坡）。
2. 在專案「設定 → 您的應用程式（網頁 `</>`）」複製 `apiKey`、`databaseURL`、`projectId`。
3. 開啟本系統的大屏或手機端 **「⚙️ 設定」** 介面，貼上上述 3 個欄位並點擊 **「儲存」**，設定會保存在該瀏覽器的 `localStorage`（`physics_tracker_firebase_config`），即時覆寫預設值。

### 方法二：Fork 專案並修改預設 `DEFAULT_FIREBASE_CONFIG`
開啟 [js/firebase-config.js](js/firebase-config.js) 第 10 行，將 `DEFAULT_FIREBASE_CONFIG` 換成您自己 Firebase 專案的完整設定物件：

```js
const DEFAULT_FIREBASE_CONFIG = {
  apiKey: "你的_API_KEY",
  authDomain: "你的專案.firebaseapp.com",
  databaseURL: "https://你的專案-default-rtdb.asia-southeast1.firebasedatabase.app",
  projectId: "你的專案_ID",
  storageBucket: "你的專案.firebasestorage.app",
  messagingSenderId: "你的_SENDER_ID",
  appId: "你的_APP_ID",
  measurementId: "你的_MEASUREMENT_ID"
};
```

> ⚠️ **Realtime Database 規則提醒**：本系統使用房間 PIN (`screens/<pin>`) 作為免登入暫存同步空間，建立資料庫時需開放 `screens` 節點讀寫權限（或定期清理舊資料），並請勿於房間中同步機密個資。

```bash
npm start
# 或直接執行

```
